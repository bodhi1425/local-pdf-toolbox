# Local PDF Toolbox

**English** · [简体中文](README.zh-CN.md)

Eight PDF tools that run entirely in your browser: merge, split, organize, compress, watermark, convert to and from images, and extract text. Files never leave your device, so it is safe for contracts, IDs and other sensitive documents.

**Try it:** https://pdf.bodhi.tools/en/

![Local PDF Toolbox screenshot](docs/screenshot.png)

## Tools

| Tool | What it does |
|---|---|
| Merge | Combine several PDFs into one; reorder files before merging |
| Split | Extract page ranges such as `1-3,5,8-10` into a new PDF, or split every page into its own PDF (downloaded as a ZIP) |
| Organize | Rotate and delete pages using page thumbnails, then export a new PDF |
| Compress | Shrink scanned or image-heavy PDFs with three strength levels (see the note below) |
| Watermark | Stamp a diagonal text watermark on every page, tiled or centered, in gray, red or blue with adjustable opacity; any language works, including Chinese |
| PDF to image | Export pages as PNG or JPG at 1.5×, 2× or 3× resolution; multi-page output is zipped |
| Image to PDF | Combine JPG, PNG, WebP or any image your browser can open into one PDF, with page size (fit, A4, Letter) and margin options |
| Extract text | Pull the selectable text out of a PDF to copy or save as `.txt` |

No watermark, no signup, no file-size or usage limits beyond what your device can handle. The interface is in English and Simplified Chinese.

**About Compress:** it re-renders each page as a JPEG image, so the output is smaller but its text is no longer selectable or searchable. Use it for scans and photo-heavy files, not for text documents you need to search.

**About Extract text:** it reads the text layer that is already in the PDF. Scanned PDFs without a text layer need OCR instead, for example [bodhi1425/ocr](https://github.com/bodhi1425/ocr).

## How it works

- [pdf-lib](https://pdf-lib.js.org) creates and edits PDFs (merge, split, rotate, delete, watermark, image to PDF).
- [PDF.js](https://mozilla.github.io/pdf.js/) renders pages to canvas (thumbnails, PDF to image, compress) and reads the text layer.
- Watermark text is drawn on a canvas and embedded as an image, which is why non-Latin scripts work without font files.
- [JSZip](https://stuk.github.io/jszip/) bundles multi-file results.

The 18 HTML pages (a home page and 8 tool pages, in two languages) are generated by `scripts/gen-pages.mjs` from the copy and SEO data in `scripts/site.config.mjs`.

## Privacy

- Your files are read and processed in your browser. The app has no upload endpoint; open the Network panel in your browser's developer tools to check.
- The PDF.js worker is bundled with the app. The page loads only fonts from Google Fonts and Fontshare.
- The hosted site at pdf.bodhi.tools uses Cloudflare Web Analytics, which counts page views without cookies. If you self-host and don't want it, remove the `cloudflareinsights` script tag from the `head` template in `scripts/gen-pages.mjs` and regenerate.

## Run it locally

Requires Node.js 20.19+ (or 22.12+) and [pnpm](https://pnpm.io).

```bash
git clone https://github.com/bodhi1425/local-pdf-toolbox.git
cd local-pdf-toolbox
pnpm install
pnpm dev     # regenerates the pages, then serves http://localhost:5173
pnpm build   # regenerates the pages, type-checks, builds the static site in dist/
pnpm gen     # regenerate the HTML pages only
```

`dist/` contains only static files. Host it on Cloudflare Pages, Netlify, GitHub Pages or any web server.

To change page text or add a tool, edit `scripts/site.config.mjs` and run `pnpm gen` instead of editing the generated `index.html` files by hand.

## Project layout

```
scripts/site.config.mjs   Page copy, SEO metadata and tool list (both languages)
scripts/gen-pages.mjs     Generates the HTML pages and public/sitemap.xml
src/tools/                One module per tool (merge.ts, split.ts, …)
src/lib/                  PDF.js setup, i18n, formatting helpers, icons
src/ui/                   Drop zone, file list and panel components
index.html, */index.html  Generated Chinese pages
en/                       Generated English pages
```
